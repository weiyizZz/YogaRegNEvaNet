# YogaRegNEvaNet
My Bachelor's Thesis: Recognition and Evaluation of Yoga Poses Based on Deep Learning

The main code is divided into three parts: classification model experiment code, evaluation model experiment code, and image human skeleton extraction code.
The classification model experiment code contains experiments corresponding to three data fusion schemes, as well as two unimodal control experiment codes. Running the code constitutes the training and testing process of the experimental models.
The evaluation model experiment code covers five poses, each with its own folder, which in turn contains experiments corresponding to three data fusion schemes as well as two unimodal control experiment codes. Running the code constitutes the training and testing process of the experimental models.
The image human skeleton extraction code is named poseEstimation.py. Given input raw image data files, it outputs skeleton coordinate data files and image data with the skeleton drawn onto them.

The image inputs are not shared here.
